01 · 문제 이해 및 준비하기

이번 시간에 해결할 문제

실외 온도와 실내 온도를 모두 보여 주고, 온도 차이가 5도 이하인지 확인할 수 있는 온도계를 만들어 보자.

02 · 문제 분석하기

구분 내용
수집해야 할 데이터 실내와 실외 온도 데이터
처리 과정 수집한 실내 온도와 실외 온도의 차이를 계산한다.
처리 결과 실내외 온도와, 적정한 온도 차인지 여부를 디스플레이에 보여 준다.

03 · 알고리즘 설계하기

실외 마이크로비트

실외 온도를 측정해 라디오로 보낸다

① 실외 온도 전송

실내 마이크로비트

받은 값을 실내 온도와 비교해 표시한다

② 실내 온도, 실외 온도를 디스플레이에 출력

③ 실내·실외 온도 차가 적정한지 여부를 디스플레이에 출력

온도 차가 5도 이내 → 하트 출력

온도 차가 5도 초과 → 체스판 출력

04 · 프로그래밍하기

Python 코드

실외 마이크로비트

from microbit import *  # 마이크로비트 사용
import radio             # 라디오 사용
radio.config(group=1)    # 라디오 그룹 1로 설정
radio.on()                # 라디오 켜기

while True:               # 무한 반복
    radio.send(str(temperature()))  # 온도 전송
    sleep(30000)           # 30초 기다림

실내 마이크로비트

from microbit import *  # 마이크로비트 사용
import radio             # 라디오 사용
radio.config(group=1)    # 라디오 그룹 1로 설정
radio.on()                # 라디오 켜기

while True:
    message = radio.receive()          # 무한 반복, 받은 메시지 저장
    if message:
        display.scroll('In')           # 'In' 스크롤
        display.scroll(temperature())  # 실내 온도 출력
        sleep(500)                     # 0.5초 기다리기
        display.scroll('Out')          # 'Out' 스크롤
        display.scroll(message)        # 실외 온도 출력
        sleep(500)                     # 0.5초 기다리기
        if abs(temperature() - int(message)) <= 5:
                                        # 온도 차가 5도 이하면
            display.show(Image.HEART)  # 하트 출력
            sleep(500)                  # 0.5초 기다리기
        else:                           # 온도 차가 5도보다 크면
            display.show(Image.CHESSBOARD) # 체스판 출력
            sleep(500)                   # 0.5초 기다리기
